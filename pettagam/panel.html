    Your rules live in _meta/rules.json in the library (create a starter one with pettagam rules --init). Views are folders of shortcuts under views/: by year, by camera, recent, large files and by tag. AI tags need an Anthropic API key and cost a little per file.

    Your rules

    : send files to the folders you choose

    The first rule that matches a file wins; files that match none are placed by the smart types. Conditions include ext, name and path wildcards, camera, category, subtype, size_over, older_than, year and tags; folders can use {year}, {month}, {category} and {camera}. Remove "off": true to switch an example on. Rules are used by the next dry run and every inbox pass.
